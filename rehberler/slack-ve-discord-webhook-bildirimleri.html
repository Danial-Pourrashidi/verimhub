Slack ve Discord Kanallarına Webhook ile Otomatik Bildirim Bağlama

Webhook Nedir ve Nasıl Çalışır?

Bir Gelen Webhook (Incoming Webhook), harici bir uygulamanın (GitHub, Google Formlar, Trello) tek bir HTTP POST isteğiyle Slack veya Discord kanalınıza anlık mesaj göndermesini sağlayan özel bir URL adresidir. Üçüncü taraf pahalı bot servislerine para ödemeden tüm bildirimlerinizi bu yöntemle bağlayabilirsiniz.

1. Bildirim Kirliliğini Önleme ve Webhook Gücü

Ekipler genellikle web sitesinden yeni bir sipariş geldiğinde, GitHub'da yeni bir kod teslim edildiğinde veya bir müşteri destek bileti açıldığında e-posta bekler. Oysa e-postalar ya spam kutusuna düşer ya da saatlerce fark edilmez.

Webhook teknolojisi ile ekibinizin ortak çalışma kanalına (Slack veya Discord) anında zengin renkli kartlar şeklinde bildirim akışı sağlayabilirsiniz.

2. Discord Kanalında Webhook Oluşturma

Discord'da webhook oluşturmak yalnızca 30 saniye sürer:

  1. Bildirim almak istediğiniz metin kanalının yanındaki Kanalı Düzenle (Dişli çark) simgesine tıklayın.
  2. Sol menüden Entegrasyonlar (Integrations) → Webhook'lar (Webhooks) yolunu izleyin.
  3. "Yeni Webhook" butonuna basın. Botunuza bir isim ve profil resmi atayın.
  4. "Webhook URL'sini Kopyala" butonuna tıklayarak bağlantıyı kaydedin.

3. Slack Kanalında Webhook Oluşturma

  1. Tarayıcınızdan api.slack.com/apps adresine gidip yeni bir App oluşturun (From scratch).
  2. Sol menüden Incoming Webhooks seçeneğini açıp anahtarı On yapın.
  3. "Add New Webhook to Workspace" diyerek mesajın düşeceği kanalı seçin ve URL'yi kopyalayın.

4. Şık JSON Mesaj Şablonu (Embed / Renkli Çerçeve)

Kanalınıza sadece düz metin yerine profesyonel renkli bir bilgi kartı göndermek için aşağıdaki JSON yapısını kullanın:

{ "username": "Satış Botu", "avatar_url": "https://verimhub.vercel.app/assets/logo.png", "embeds": [ { "title": "🎉 Yeni Müşteri Kaydı!", "description": "Web sitemiz üzerinden yeni bir demo randevusu oluşturuldu.", "color": 3066993, "fields": [ { "name": "Müşteri Adı", "value": "Ahmet Yılmaz", "inline": true }, { "name": "Plan", "value": "Kurumsal Pro", "inline": true } ], "footer": { "text": "VerimHub Otomasyon Sistemi" } } ] }

5. Örnek Kullanım: GitHub ve Web Form Bildirimleri

  • GitHub Entegrasyonu: GitHub Repo ayarlarından Webhooks bölümüne gidin. Discord webhook URL'nizin sonuna /github ekleyin (örnek: https://discord.com/api/webhooks/.../github). Artık her push ve pull request anında Discord'a düşer.
  • Google Formlar: Google Apps Script ile tek satırlık UrlFetchApp.fetch() çağrısı yaparak form cevaplarını ekibinize aktarabilirsiniz.

6. Sıkça Sorulan Sorular (SSS)

Soru 1: Webhook URL'sini başkaları görürse ne olur?

Webhook URL'si bir şifre gibi korunmalıdır. Bu bağlantıya sahip olan herkes kanalınıza bot adına mesaj gönderebilir. Eğer sızdırılırsa hemen panodan silip yenisini üretmelisiniz.

Soru 2: Webhook mesaj sınırları var mı?

Hem Discord hem de Slack saniyede ortalama 5 ila 30 mesaj arası rate-limit uygular. Normal bildirimler için bu sınır fazlasıyla yeterlidir.
